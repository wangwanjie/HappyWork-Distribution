# HappyWork 1.5.3

基于 RustDesk 主分支 1.5.3（构建号 71），同步上游截至 `0bfe22083df9c6319d917849ab72c1efb3920d7e` 的改动，保留 HappyWork 应用名称、`cn.vanjay.happywork` Bundle ID 与现有配置兼容性。

本版开始从本仓库检查后续更新。客户端会验证 Release 中的签名元数据及 DMG 校验和，再安装适合当前 Mac 架构的版本。1.5.0 尚不包含此更新地址，需要手动安装一次 1.5.3。

下载时请选择对应架构：Apple 芯片使用 `arm64`，Intel 使用 `x86_64`。两个 DMG 均经过 Apple Developer ID 签名与公证。

Linux x86_64 可下载 `HappyWork-1.5.3-linux-x86_64.deb`。它以独立的 `happywork` 包名安装交互式客户端，不会覆盖 RustDesk，也不会自动安装或启用 systemd 服务；Linux 更新需手动下载新版包。

Windows x86_64 可下载 `HappyWork-1.5.3-windows-x86_64.exe`。这是便携单文件包，**未进行 Windows 代码签名**，运行时可能出现 SmartScreen 提示。本版公开签名更新清单只包含 macOS 资产；Windows 的后续自动更新从下一版的跨平台签名清单开始。
